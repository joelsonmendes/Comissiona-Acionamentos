# ComissionaIA • Acionamentos Industriais

PWA estática para apoiar a Situação de Aprendizagem **Comissionamento de um Sistema de Acionamento Elétrico Industrial**.

## Funcionalidades
- Identificação do projeto/equipe
- Checklist de segurança
- Leitura de placa do motor e análise didática
- Seleção e validação básica de componentes
- Checklist de montagem
- Registro de medições e cálculo de desvios
- Diagnóstico orientado de falhas com cenários
- Checklist final de comissionamento
- Registro de produto/evidências
- Relatório automático imprimível em PDF
- Exportação/importação JSON
- Salvamento local no navegador
- PWA instalável e funcionamento offline após o primeiro acesso

## Publicar no GitHub Pages
1. Crie um repositório, por exemplo `comissionaia-acionamentos`.
2. Envie todos os arquivos deste projeto para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Publicar na Vercel
Como o projeto é estático, basta importar o repositório e usar as configurações padrão. Não há chave de API nem variável de ambiente.

## Uso didático
A ferramenta não substitui os procedimentos formais de segurança, manuais do fabricante ou supervisão docente. As validações são didáticas e servem para apoiar o raciocínio e o registro das evidências.
